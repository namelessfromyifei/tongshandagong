# 通山打拱 · 单机试玩版

一个可在浏览器本地打开的通山打拱（屋规版）游戏：**1 真人（南家）+ 3 AI**，单文件出牌。

规则依据 `规格.md`（2026-10-19 全量拍板），与根目录的《通山打拱规则.md》同源。

---

## 运行

```bash
# 在 claude/ 目录下
python -m http.server 8901
# 浏览器打开 http://127.0.0.1:8901
```

直接双击 `index.html` 也可（资源为相对路径，无 ES Module，file:// 可用）。

## 测试

```bash
node tests/engine.test.js   # 82 项，覆盖牌具/牌型/比较/结算/流程/模拟
```

## 规则要点（已拍板口径）

- **牌具**：2 副扑克 + 4 王 = 112 张，8 王为癞子；4 人各 28 张。
- **王（癞子）**：任意组合内可代任意牌并指定花色（五十K 默认凑同花）；**单独出固定算 3**，与真 3 无区别。
- **叫牌**：庄家随机叫张非王牌；持同张者为其对家（**明鸡**，打出叫牌才公开）。若庄家两张同牌都在自己手则跳过重叫。
- **硬牌（明吞）**：可宣布 1 打 3，只看名次（硬牌者一游则胜，任一对方先跑则负）。
- **牌型**：单/对/连对(无2)/三条/飞机(无2)，无三带一/三带二。
- **炸弹**（大小按番）：
  - 五十K（最小，同花>杂，同花分花色，杂先出为大）
  - 无番炸（4/5/6 张同牌：仅压牌，不能领出）
  - 番炸：7/8 张同牌（软1/硬2番）、滚笼（双路线，逐级翻番）、王炸（4~8 王 = 4~12 番，同番最大）
  - 滚笼等番比大小：**逐级比点数，点数高者胜**；点数**环形**，可跨 A−2 且 2 与 3 相邻（`AAAA 2222`、`2222 3333`、`2222 3333 4444` 都合法）。
- **抓分**：5/10/K（200 分），每轮赢家取分。
- **结算（2V2）**：半番=1分，1番=2分；**队内同输同赢，全额不除二**；
  每人 = ±(基础 + Δ)；基础 = 半番×输方没跑人数（0 分翻倍）；Δ = 归赢队滚笼 − 归输队滚笼，**不封底**。
- **结算（硬牌）**：基础每人 2 番（胜→三家各输2番；败→硬牌者向三家各输2番），叠加滚笼 Δ。
- **接风**：明鸡后对家接风，未明鸡下家接风。
- **下一局叫牌**：由本局一游叫牌。

> 已解决的拍板决策见 `规格.md` 决策记录；其中「8 张同牌炸按软 1 番 / 硬 2 番」为规格外缺口的默认设定（原表只列到 7 张），如需调整在 `js/engine.js` 的 `analyzePlay` 中改即可。

## 已知简化（v1）

- AI 偏「先出最小、压牌用小炸」的保守策略，不会主动策划滚笼为王。
- 硬牌声明：开局庄家回合可点按钮（真人）/AI 庄家有 12% 概率自动声明。
- 结算滚笼归属：打出滚笼且跑完归本队、没跑归对方；硬牌模式按跑/未跑归属到「硬牌方/三家方」，金额伺服保持零和。

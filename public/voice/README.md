# 本地语音包

把录制/合成的音频片段放到 `public/voice/<包名>/`，再把 `manifest.example.json` 复制为
`manifest.json` 并改成实际文件名即可启用。

启用后手牌播报会**优先使用语音包**，按词条无缝拼接播放；某个词条缺失或加载失败时，
整句自动回退到系统 TTS，不会没声音。

> 仓库当前自带一个**临时测试包**（`manifest.json` + `dui/8/guo.wav` 三段提示音），
> 用于验证语音包通道。之后直接用真人录音替换同名文件即可；其余未配置的词条会自动回退 TTS。

## 目录结构

```
public/voice/
├── manifest.json          # 由 manifest.example.json 复制而来（不提交真实音频时可保留示例）
├── manifest.example.json  # 词条与文件名模板
└── default/               # 默认语音包目录
    ├── dui.mp3            # “对”
    ├── 8.mp3              # “8”
    └── ...
```

## manifest.json

```json
{
  "default": "default",
  "packs": {
    "default": {
      "label": "本地语音包",
      "base": "voice/default/",
      "files": { "对": "dui.mp3", "8": "8.mp3" }
    }
  }
}
```

- `base` 是相对站点根目录的路径（服务器托管的是 `public/`）。
- 可以配置多套包；客户端可用 localStorage `tsVoicePack` 指定，未指定时用 `default`。
- 音频格式：mp3 / wav / ogg 均可，建议单声道、去掉首尾静音、统一音量。

## 需要录制的词条（共 41 条）

| 类别 | 词条 |
| - | - |
| 牌点 | `3` `4` `5` `6` `7` `8` `9` `10` `2` `K` `王` |
| 特殊读法 | `沟`（J） `圈`（Q） `兼`（A） |
| 数量 | `11` ~ `20`（4~10 复用牌点读音） |
| 牌型 | `对` `三个` `连对` `飞机` `五十K` `滚笼` `张` `个` |
| 动作/状态 | `过` `不独` `明独` `插底` |
| 名次 | `一` `二` `三` `四` `游` |

实际播报示例：`对`+`8`、`9`+`张`+`8`、`4`+`个`+`王`、`五十K`、`滚笼`、`过`、`不独`、`插底`、`二`+`游`。

> 牌点 3~10 与数量 4~10 共用同一个音频文件；11~20 只用于 9 张以上大炸。

## 校验

录制完成后运行：

```bash
node tools/voice-pack-check.js
```

脚本会检查 `manifest.json` 里列出的文件是否存在，并提示缺失的词条。

# 本地语音包

把录制/合成的音频片段放到 `public/voice/<包名>/`，再把 `manifest.example.json` 复制为
`manifest.json` 并改成实际文件名即可启用。

启用后手牌播报会**优先使用语音包**，按词条无缝拼接播放；某个词条缺失或加载失败时，
整句自动回退到系统 TTS，不会没声音。

> 仓库当前自带一个**临时测试包**（`manifest.json` + `dui/8/guo.wav` 三段提示音），
> 用于验证语音包通道。之后直接用真人录音替换同名文件即可；其余未配置的词条会自动回退 TTS。

## 目录结构

```
public/voice/
├── manifest.json          # 由 manifest.example.json 复制而来（不提交真实音频时可保留示例）
├── manifest.example.json  # 词条与文件名模板
└── default/               # 默认语音包目录
    ├── dui.mp3            # “对”
    ├── 8.mp3              # “8”
    └── ...
```

## manifest.json

```json
{
  "default": "default",
  "packs": {
    "default": {
      "label": "本地语音包",
      "base": "voice/default/",
      "files": { "对": "dui.mp3", "8": "8.mp3" }
    }
  }
}
```

- `base` 是相对站点根目录的路径（服务器托管的是 `public/`）。
- 可以配置多套包；客户端可用 localStorage `tsVoicePack` 指定，未指定时用 `default`。
- 音频格式：mp3 / wav / ogg 均可，建议单声道、去掉首尾静音、统一音量。

## 语音包词条（整句录音）

命名规则：`张数-点数.m4a`，例如 `1-3.m4a`（单张 3）、`2-K.m4a`（对 K）、`3-A.m4a`（三个 A）、`4-W.m4a`（4 个王炸）。

| 类别 | 词条 |
| - | - |
| 单张 | `1-3` ~ `1-2`、`1-J` `1-Q` `1-K` `1-A`、`1-W` |
| 对子 | `2-3` ~ `2-2`、`2-J` `2-Q` `2-K` `2-A`、`2-W` |
| 三条 | `3-3` ~ `3-2`、`3-J` `3-Q` `3-K` `3-A`、`3-W` |
| 王炸 | `4-W` ~ `12-W`（按王数量） |
| 动作/状态 | `过` `不独` `明独` `插底` `滚笼` `继续继续` `快点` `明鸡` `炸弹` `不要` |

- `W` = 王；`J/Q/K/A` 直接用字母命名即可（录音里读「沟/圈/凯/兼」都可以）。
- 同点数大炸（4 张以上同牌，如 4 张 K）使用 `张数-点数` 命名；未录制时自动回退 TTS。
- 连对、飞机、五十K、名次（一游~四游）等暂未列入，缺录音时同样回退 TTS。
- 换行/继续等彩蛋录音：`继续继续`（每局结束时播）、`快点`（点「快点」按钮时播）。

## 校验

录制完成后运行：

```bash
node tools/voice-pack-check.js
```

脚本会检查 `manifest.json` 里列出的文件是否存在，并提示缺失的词条。

# 微信头像昵称授权接入（公众号 H5）

目标：玩家在微信内打开游戏时，自动走公众号网页授权，直接使用微信头像和昵称进入房间，不再手动设置昵称。

> **重要前提**：微信网页授权**不支持 IP 地址**。必须使用已备案域名，并把该域名配置为公众号的「网页授权域名」。仅通过 `http://服务器IP:8080` 访问时，服务端会自动降级为手动昵称。

---

## 一、需要准备什么

| 条件 | 说明 |
|---|---|
| 已认证服务号 | 订阅号没有网页授权能力；服务号需完成微信认证 |
| 已备案域名 | 如 `game.example.com`，在阿里云完成 ICP 备案并解析到服务器 |
| HTTPS | 微信内建议强制 HTTPS；可用阿里云免费证书或 Let's Encrypt |
| 公众号后台配置 | 设置与开发 → 公众号设置 → 功能设置 → **网页授权域名** |
| AppID / AppSecret | 公众号后台「基本配置」中获取 |

当前项目通过 `IP:8080` 访问，只是完成了功能代码；以上条件补齐后才会真正走微信授权。

---

## 二、服务器配置（阿里云 + Nginx）

### 1. 域名与备案

1. 在阿里云购买域名并完成 **ICP 备案**（国内服务器必须，通常数个工作日）。
2. 添加 DNS `A` 记录：`game.example.com` → 服务器公网 IP。
3. 云服务器安全组放行 **80 / 443**；8080 只供本机 Nginx 反代，不必对公网开放。

### 2. 申请 HTTPS 证书

- 阿里云「数字证书管理服务」申请免费证书，下载 Nginx 格式；或使用 certbot：

```bash
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d game.example.com
```

### 3. Nginx 反向代理

```nginx
server {
    listen 80;
    server_name game.example.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name game.example.com;

    ssl_certificate     /etc/nginx/ssl/game.example.com.pem;
    ssl_certificate_key /etc/nginx/ssl/game.example.com.key;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # Socket.IO WebSocket 升级
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 120s;
    }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

### 4. 公众号配置「网页授权域名」

公众号后台 → 设置与开发 → 公众号设置 → 功能设置 → **网页授权域名**：

- 填写 `game.example.com`（只填域名，不带 `https://`、路径或端口）。
- 按提示下载 `MP_verify_XXXXXXXX.txt`，放到项目的 `public/` 目录（服务器上即 `/home/admin/tongshandagong/public/`），确认能通过 `https://game.example.com/MP_verify_XXXXXXXX.txt` 访问。
- 同一个域名也可一并配置到「JS 接口安全域名」。

## 三、启动服务

```bash
cd /home/admin/tongshandagong
npm install --production

export NODE_ENV=production
export PORT=8080
export WX_APPID=wx1234567890abcdef
export WX_APPSECRET=你的AppSecret
export WX_OAUTH_BASE=https://game.example.com
export SESSION_SECRET="$(openssl rand -hex 32)"
export ROOM_IDLE_KICK_MS=300000
export OFFLINE_KICK_MS=180000

pm2 start server.js --name tongshandagong --update-env
pm2 save
```

推荐改用 `ecosystem.config.js` 固定环境变量，避免 PM2 重启后丢失：

```js
module.exports = {
  apps: [{
    name: 'tongshandagong',
    script: 'server.js',
    env: {
      NODE_ENV: 'production',
      PORT: 8080,
      WX_APPID: 'wx1234567890abcdef',
      WX_APPSECRET: '你的AppSecret',
      WX_OAUTH_BASE: 'https://game.example.com',
      SESSION_SECRET: '换成固定随机字符串',
    },
  }],
};
```

```bash
pm2 start ecosystem.config.js && pm2 save
```

> `SESSION_SECRET` 必须固定。不设置时服务端每次启动随机生成，所有微信登录态会在重启后失效。
> `WX_MOCK=1` 仅在 `NODE_ENV=production` 以外生效，生产环境不会误开模拟登录。

## 四、验证

1. 微信内打开 `https://game.example.com/`；
2. 应自动跳到微信授权页，点击「允许」；
3. 回到大厅后，昵称行消失，显示微信头像、昵称；
4. 创建/加入房间，牌桌头像圈显示微信头像，其他玩家也能看到；
5. 刷新页面，30 天内无需重复授权（签名 Cookie）。

浏览器直接打开（非微信）不会弹授权，仍可手动输入昵称。

本地无公众号联调：

```bash
WX_MOCK=1 SESSION_SECRET=dev-secret node server.js
# http://localhost:8080 会出现「微信授权」按钮，点击即模拟登录
node tests/wx-auth.js   # 自动化验证授权流程
```

## 五、实现说明

| 环节 | 行为 |
|---|---|
| 授权入口 | `GET /api/wx/start?next=/`：种下 state Cookie 后跳转微信 |
| 回调 | `GET /api/wx/callback`：校验 state，服务端换取 access_token + userinfo |
| 登录态 | 签名 HttpOnly Cookie `ts_wx`，30 天有效，内容含 openid/昵称/头像 |
| 身份优先 | Socket 建连时从 Cookie 解析身份，建房/进房/重连以服务端身份为准 |
| 头像下发 | 房间快照的 `seats[].avatar` 下发给所有客户端；`openid` 不会下发 |
| 降级 | 未配置、非微信环境或授权失败 → 保留手动昵称 |
| 本地模拟 | `WX_MOCK=1`：不请求微信接口，返回固定的「微信测试用户」和占位头像 |

相关接口：

- `GET /api/wx/config` — 是否启用、是否模拟、是否微信 UA
- `GET /api/me` — 当前登录身份（未登录 `{ok:false}`）
- `GET /api/wx/start` — 发起授权
- `GET /api/wx/callback` — 微信回调
- `GET /api/wx/logout` — 清除登录态并回大厅

## 六、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `redirect_uri 参数错误` / 10003 | 公众号「网页授权域名」与实际回调域名不一致，或回调带了端口/路径配置错误。检查 `WX_OAUTH_BASE` 与后台配置 |
| 40029 / 40163 | code 无效或已被使用。确认回调只处理一次；重新从 `/api/wx/start` 发起 |
| 40013 / 40125 | AppID / AppSecret 错误，检查公众号后台基本配置 |
| 微信内打开仍显示手动昵称 | 未配置 `WX_APPID/WX_APPSECRET`，或页面不是通过已配置域名打开，或用户此前拒绝过授权（点「微信授权」重试） |
| 授权后头像不显示 | 用户未设置头像或微信返回空 `headimgurl`；前端会回退为昵称首字，不影响游戏 |
| 重启后要重新授权 | 未固定 `SESSION_SECRET`；按上文设置固定值 |
| 授权页提示“请在微信客户端打开” | 在普通浏览器打开了授权链接；应只在微信内自动发起 |
| 一直跳转授权页 | 检查 `/api/me` 是否能读到 `ts_wx` Cookie；HTTPS 下确认 Nginx 传了 `X-Forwarded-Proto: https`（Cookie 带 Secure） |

## 七、隐私说明

- 仅使用微信昵称、头像和 openid：昵称/头像用于牌桌展示，openid 仅用于服务端识别同一玩家（重连、防冒用），不会下发给其他玩家。
- 登录态为签名 HttpOnly Cookie，前端 JS 无法读取或篡改。
- 若需正式上线，建议在大厅补充隐私政策与用户协议入口，并按微信平台要求说明信息用途。
